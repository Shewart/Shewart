shadcn/ui for **Blazor**. Accessible, Tailwind-styled components that the CLI copies into your project, or that you install as one NuGet package.

### [ShellUI Native](https://native.shellui.dev)

The same design system for **.NET MAUI** and **Avalonia**, as plain C# controls the CLI copies into your app. No package to depend on.

[![Stars](https://img.shields.io/github/stars/shellui-dev/shellui-native?style=flat-square&label=stars&labelColor=000&color=333)](https://github.com/shellui-dev/shellui-native)

`dotnet tool install -g ShellUI.Native.CLI --prerelease`

The docs framework for **.NET**. Markdown-driven sites with live Blazor previews, versioned docs, `Cmd+K` search and a static export.
